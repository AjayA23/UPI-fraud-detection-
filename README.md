# 💳 UPI Fraud Detection System

An AI-powered UPI Fraud Detection System that analyzes transaction data and identifies potentially fraudulent transactions using Machine Learning.

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly
- Machine Learning

## ✨ Features

- 💳 UPI Transaction Analysis
- 🚨 Fraud Detection
- 🤖 Machine Learning Prediction
- 📊 Interactive Dashboard
- 📈 Transaction Statistics
- 🔍 Fraud Risk Analysis
- ⚡ Real-time Prediction

## 🎯 Objective

The main objective of this project is to detect potentially fraudulent UPI transactions using Machine Learning and provide an interactive dashboard for analyzing transaction patterns.
